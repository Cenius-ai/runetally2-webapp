usage: runetally [-h] [--file PATH] [--no-color] [--version] <command> ...

RuneTally2 - catalog runic inscriptions, sort by stave width, score pigment wear.
Offline, one JSON catalog, guarded by a local operator passphrase.

positional arguments:
  <command>
    auth       create or inspect the operator passphrase
    add        add one inscription
    list       print the fixed-width catalog table
    show       print one inscription with full fields
    edit       update named fields of one inscription
    delete     delete one inscription (requires --yes)
    import     import inscriptions from a TSV file
    bands      print the stave band rubric and the wear scale

options:
  -h, --help   show this help message and exit
  --file PATH  catalog JSON file (default: ./runetally.json; env
               RUNETALLY_FILE)
  --no-color   never emit ANSI colour
  --version    show program's version number and exit

Stave width bands (mm):
  narrow   width <= 4.0
  medium   4.0 < width <= 8.0
  broad    width > 8.0
  unset    no width recorded (null)

Pigment wear: 0 pristine, 1 slight, 2 light, 3 moderate, 4 heavy, 5 lost; null = unset.

Passphrase: RUNETALLY_PASSPHRASE for non-interactive use (demo account: cenius / cenius).

Examples:
  runetally auth init
  runetally add --name "Broby stone" --site Broby --period "Viking Age" --stave-width 3.2 --wear 4
  runetally list --sort stave-band --band narrow
  runetally import examples/inscriptions.tsv
